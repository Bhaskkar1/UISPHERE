# GDG on Campus (demo site)
React + Vite + GSAP ScrollTrigger + Lenis.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

Edit events in `src/data/events.js`. For a real hero photo, put `hero.jpg` in `public/`
and swap the `.scene` div in `src/components/Hero.jsx` for an <img>.
Registrations are demo-only and saved to localStorage key `gdg-demo-regs`.
